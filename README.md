# Симулятор торговли на истории S&P 500

Прогоняет историю дневных цен день за днём и считает, как отработала бы торговая стратегия. Минимальная версия: одна бумага, дневные свечи, рыночные приказы.

## Установка и запуск

```
pip install -r requirements.txt
python sp500_sim.py                    # SPY с 2000 года, две стратегии
python sp500_sim.py --ticker ^GSPC     # сам индекс вместо SPY
python sp500_sim.py --start 2010-01-01 # другая дата начала
python sp500_sim.py --no-plot          # только таблица, без графика
python sp500_sim.py --test             # проверка самого симулятора
```

Цены скачиваются через `yfinance` и сохраняются в `prices.csv`. При следующем запуске интернет не нужен. Чтобы скачать заново, удалите этот файл. Если меняете `--ticker` или `--start`, тоже удалите `prices.csv`, иначе возьмутся старые данные.

SPY — фонд на S&P 500, его можно купить, и цены в нём учитывают дивиденды. `^GSPC` — сам индекс, без дивидендов.

## Как это работает

1. Решение принимается по цене закрытия дня i.
2. Исполняется оно по цене открытия дня i+1, с комиссией и проскальзыванием.
3. Стратегия получает только историю до дня i включительно, будущего у неё нет.

## Своя стратегия

Стратегия — класс с методом `target(hist)`. Он получает таблицу цен до сегодняшнего закрытия и возвращает желаемую долю акций в портфеле: от 0.0 (всё в деньгах) до 1.0 (всё в акциях).

```python
class MyStrategy:
    def target(self, hist):
        return 1.0 if hist["Close"].iloc[-1] > hist["Close"].iloc[-50:].mean() else 0.0
```

Добавьте её в список в конце `sp500_sim.py`:

```python
for name, strat in [("Купить и держать", BuyAndHold()),
                    ("Тренд SMA-200", SmaTrend(200)),
                    ("Моя", MyStrategy())]:
```

## Настройки в `run`

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `cash` | 10 000 | стартовые деньги |
| `commission` | 0.0005 | комиссия с каждой сделки (0,05%) |
| `slippage` | 0.0005 | цена хуже на эту долю: покупка дороже, продажа дешевле |
| `min_change` | 0.01 | не торговать, если доля акций меняется меньше чем на 1% |

## Что показывает отчёт

Итог в долларах, доходность, доходность в год (CAGR), максимальная просадка, Sharpe (без безрисковой ставки), число сделок. Плюс график капитала в логарифмической шкале и график просадки.

## Тесты

`python sp500_sim.py --test` проверяет:

- «купить и держать» без комиссий даёт ровно рост цены от открытия второго дня до последнего закрытия;
- стратегия, которая ничего не делает, оставляет деньги нетронутыми;
- комиссии всегда уменьшают результат.

## Что пока не умеет

Несколько бумаг, лимитные заявки, короткие продажи и маржа, минутные данные, разделение истории на период подбора и период проверки. Данные `yfinance` среднего качества, в них нет компаний, которые вышли из индекса или обанкротились, поэтому результаты на отдельных акциях будут завышены.
